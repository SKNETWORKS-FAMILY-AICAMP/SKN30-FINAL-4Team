# DL14 — 모델 2 FT-Transformer vs LightGBM (동일 분할)

> 계획서 3.5: 현재 LGBM MAE 0.5028 보다 유의미하게 좋아지지 않으면 LGBM 유지.

```text
n=2205 / 그룹 2075 / GroupKFold(5) by program_stem — 셔플 없는 결정적 분할
타깃 log10(기업/과제당 지원액) / feature +자부담·추출신뢰도
d_token 32 / blocks 3 / heads 4 / dropout 0.1 / L1 loss / epochs 200
```

두 모델이 **글자 그대로 같은 fold 인덱스**를 봅니다. GroupKFold 는 셔플이
없어 결정적이고, 같은 실행 안에서 한 번 만든 분할을 양쪽에 넘겼습니다.
