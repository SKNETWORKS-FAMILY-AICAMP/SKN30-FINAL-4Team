# M68 — Residual Expert / Mixture-of-Experts 실험

> 질문: **M65 의 전역 예측을 유지한 채 residual expert 또는 MoE 를 얹으면,
> routing 실패 위험 없이 금액대별 패턴을 살려 OOF MAE 를 낮출 수 있는가?**

## 0. 같은 조건 / 바뀐 것

```text

target   log10(per_recipient), basis=stated_cap
split    GroupKFold(5), group=program_stem / normalized_title
feature  m2-feat-v2 (구조화 + 제목 SVD64, fold 내부 적합)
바뀐 것  예측 경로만 — 단일 회귀 -> base 예측 + residual 보정(전역/구간/MoE/극단)
residual fold train 내부 inner GroupKFold(5) 의 out-of-sample base 예측
```

> validation 에서는 보정 스케일이 맞지 않았을 것입니다. 그래서 inner OOF 를 씁니다.
