# M63 — 모델 2(M56)를 수정 데이터로 동일조건 재평가

> 지시서 Model 2 우선순위 4번. **새 모델을 찾지 않습니다.**

```text
바꾸는 것   입력 데이터셋 하나 (design_features -> design_features_v2, M62)
그대로      타깃 stated_cap · 필터 · 비교군 사다리 · feature 규격 ·
            XGBoost 파라미터 · GroupKFold(5) · baseline · seed 42
```

M56 승격 때(STEP 3)와 같은 규율입니다 — 두 데이터셋을 **같은 split 루프**
**안에서** 학습해 fold 가 달라 생긴 차이를 결과로 오독하지 않습니다. 그게
가능한 이유는 M62 가 타깃·필터를 건드리지 않아 대상 행이 **1877건으로 같기**
때문입니다(스크립트가 시작할 때 `row_id` 집합 일치를 검사하고, 다르면 멈춥니다).

```text
필터 v1  {'전체': 3963, '지원성격_결측_제외': 58, '기업당지원액_결측_제외': 1694, '파싱오류범위_제외': 84, '총예산나눗셈(평균)_제외': 250, '필수축_결측_제외': 0, '최종': 1877}
필터 v2  {'전체': 3963, '지원성격_결측_제외': 58, '기업당지원액_결측_제외': 1694, '파싱오류범위_제외': 84, '총예산나눗셈(평균)_제외': 250, '필수축_결측_제외': 0, '최종': 1877}
```

입력에서 실제로 달라진 칸은 이렇습니다.

| 컬럼 | 값이 바뀐 행 |
|---|---:|
| `support_method` | 114 |
| `support_unit` | 35 |
| `amount_type` | 0 |
| `support_count` | 0 |
| `support_ratio` | 1 |
| `self_burden_ratio` | 78 |
| `project_duration` | 524 |
| `per_recipient` | 0 |
| `title` | 0 |

타깃(`per_recipient`)·제목·금액은 **한 행도 바뀌지 않았습니다.** 그래서 이
비교는 *같은 모델·같은 타깃·같은 행에서 입력 품질만 바뀌면 얼마나 움직이는가*
를 재는 것입니다.

> 위 표에서 `support_count` 만 성격이 다릅니다. 근거문 수정과 무관하고,
> v1 이 `business_taxonomy.parquet` 의 M32 파서 수정 **이전**에 만들어져
> 얼어 있었기 때문에 생기는 상류 드리프트입니다(M62 3절). 이번 수정의
> 효과로 읽지 않습니다.

## 1. 결과 — 같은 split, 데이터만 교체

| 지표 | M56 on v1 (현행) | M56 on v2 (수정) | |
|---|---:|---:|---|
| MAE(log10) | 0.4155 | 0.4117 | 개선 |
| v1 baseline 대비 개선 | 21.8% | 22.5% | 개선 |
| 2배 이내 | 48.8% | 49.2% | 개선 |
| 3배 이내 | 67.6% | 68.1% | 개선 |
| 중앙절대오차 | 0.3122 | 0.3089 | 개선 |
| 비교군중앙값 baseline | 0.5315 | **0.5223** | 개선 |
| *각자의* baseline 대비 개선 | 21.8% | 21.2% | 사실상 동일 |

**마지막 두 줄이 이 절에서 가장 중요합니다.** 비교군 중앙값 baseline 은
모델이 아니라 **비교군 자체가 금액을 얼마나 잘 설명하는가**입니다. 그 값이
0.5315 → 0.5223 로 같이 내려갔다는 것은 `support_method` 를 바로잡자
**비교군이 실제로 더 동질해졌다**는 뜻입니다 — 모델과 무관한 독립 증거입니다.
그래서 각자의 baseline 대비 개선율로 재면 두 세대가 거의 같습니다. **모델이**
**좋아진 것이 아니라 모델과 baseline 이 함께 좋아졌습니다.**

> 개선율의 **분모는 v1 baseline 하나로 고정**했습니다. 데이터가 바뀌면
> 비교군 중앙값 baseline 도 같이 움직이는데, 분모까지 움직이면 두 세대를
> 견줄 수 없습니다. 참고로 수정 데이터에서 baseline 자체는 0.5223 입니다.
> (비교군이 제대로 갈리면서 baseline 도 같이 좋아졌다는 뜻입니다)

**짝지어서 다시 봅니다.** 두 열은 같은 fold·같은 행이므로 행 단위로
오차를 짝지을 수 있고, 그러면 차이의 분산이 MAE 각각의 분산보다 훨씬
작아집니다. 입력이 바뀐 것은 일부 컬럼뿐이지만 학습기가 다시 적합되므로
예측값 자체는 1877행 전부 조금씩 달라집니다 — 그래서 *몇 행이 달라졌는가*가
아니라 *어느 쪽으로 달라졌는가*를 봅니다.

| 짝지은 절대오차 차이 (v1 − v2) | 값 |
|---|---:|
| 평균 | **+0.00374** |
| 부트스트랩 95% 구간 | -0.00031 ~ +0.00783 |
| P(차이 > 0) | 0.9668 |
| v2 가 더 정확한 행 | 958 / 1877 (51.0%) |
| Wilcoxon 부호순위 p | 0.11269 |

**구간이 0을 품고 부호검정도 무작위와 구별되지 않습니다.** MAE 0.4155 →
0.4117 은 **표본 흔들림과 구별되지 않는 차이**입니다. 모델 2 의 예측 성능은
데이터 수정으로 사실상 움직이지 않았다고 읽는 것이 맞습니다.

> 부트스트랩은 행 단위라 같은 사업 계열이 여러 번 뽑혀 구간이 오히려
> **낙관적**입니다. 그런데도 0을 품습니다. 계열 단위로 다시 뽑으면 더
> 넓어질 뿐이라 결론은 바뀌지 않습니다.

**엄격 그룹(정규화 제목)에서도** 같은 방향인지 확인합니다 — 제목 텍스트를
feature 로 쓰는 순간 '지역·연도만 다른 같은 사업 계열'이 새 누수 경로가 되므로,
M55 이후로는 이쪽이 진짜 기준입니다.

| 그룹 기준 | v1 개선율 | v2 개선율 |
|---|---:|---:|
| `program_stem` (표준) | 0.2182 | 0.2254 |
| `normalized_title` (엄격) | 0.2078 | 0.2173 |

## 3. 예측구간과 비교군 실용성 등급

| | 커버리지(명목 80%) | 구간폭 중앙값 | 참고 가능 / 범위 넓음 / 제시 어려움 |
|---|---:|---:|---|
| v1 (현행) | 0.803 | 25.1배 | 16 / 12 / 1 |
| v2 (수정) | 0.807 | 24.1배 | 16 / 15 / 0 |

등급은 담당자에게 P10~P90 을 그대로 낼 수 있는 비교군이 몇 칸인가입니다.
비교군 축(`support_method`·`support_unit`)이 바뀌었으므로 칸 자체가 재편됩니다 —
칸 수를 v1 과 1:1 로 견주지 않고 구성이 어떻게 달라졌는지로 읽습니다.

## 4. 선택 실험 (지시서 '필요할 때만')

지시서가 '필요할 때만' 이라고 한 둘입니다. 1절에서 데이터 수정만으로는
예측 오차가 움직이지 않는다고 나왔으므로 **한 번** 돌렸습니다.

| 후보 | MAE(log10) | v1 baseline 대비 |
|---|---:|---:|
| C-a XGB (수정 데이터, 기준) | 0.4117 | +22.5% |
| C-b XGB+LGBM 단순평균 | 0.4169 | +21.6% |
| C-c XGB + 비교군 잔차보정(inner OOF) | 0.4136 | +22.2% |

**둘 다 기준보다 나쁩니다. 미채택.**

잔차 보정에서 한 가지를 적어 둡니다. 처음에는 train fold 의 **in-sample**
잔차로 비교군 중앙값을 잡았고 그때는 기준보다 좋게 나왔습니다. 그런데
XGBoost 800 트리는 train 을 거의 맞히므로 그 잔차 중앙값은 0 근처로
눌리고, 보정이 아니라 **미세한 과적합 방향으로 밀어준** 것에 가깝습니다.
train fold 안에서 inner GroupKFold(3) 로 OOF 잔차를 다시 잡자
뒤집혔습니다. **측정 방식이 결론을 만들던 자리**라 그대로 남깁니다.

## 5. 읽는 법

공표 수치(M56)는 MAE **0.4155** / 개선 **21.8%** / 2배내 **48.8%** 입니다.
v1 열이 그 값을 정확히 재현하고, v2 열과의 차이가 **데이터 품질 수정이**
**모델 2 에 준 것 전부**입니다.

```text
예측 오차          유의하게 움직이지 않았다 (짝지은 차이의 95% 구간이 0을 품는다)
비교군 baseline    0.5315 -> 0.5223 로 내려갔다 (비교군이 더 동질해졌다)
예측구간           폭 25.1배 -> 24.1배, '제시 어려움' 등급 1칸 -> 0칸
선택 실험 2종      둘 다 기준보다 나쁘다. 미채택
```

지시서의 종료 조건("실질 개선이 없으면 추가 모델 실험은 종료한다")에
답하면 **모델 2 쪽 추가 실험은 종료**입니다. 예측 오차에서는 실질 개선이
없고, 수정이 남긴 것은 **1차 산출물인 percentile 조회의 정합성** 쪽입니다
— 모델 2 는 회귀가 아니라 비교군 percentile 이 주 산출물이므로 그쪽이
더 중요한 축입니다.

> 이 문서는 canonical 을 바꾸지 않습니다. 승격은 M56 이 세운 절차(재현성 고정
> → 누수 최종 점검 → 동일조건 비교 → 서빙 동기화 · 점검표 11항목)를 다시
> 통과해야 하고, 그 판단 근거는 여기 수치입니다. 승격 근거는 *MAE 개선*이
> 아니라 **비교군 축의 정합성**이라는 점을 같이 적어 둡니다.
