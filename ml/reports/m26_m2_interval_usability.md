# 모델 2 — 예측구간 실용성 판정

> 최종개선계획서 3순위(69~94행): "MAE 소폭 개선보다 coverage 유지 +
> interval width 감소"

## 1. 여기서 하는 일은 "더 좁히기"가 아닙니다

M22 에서 이미 쟀습니다 — 비교군별 보정으로는 43.7배 → 41.1배, **6% 밖에**
**안 좁아집니다.** 칸마다 예측 난이도가 비슷해서 나눠도 얻는 게 없습니다.

대신 **어느 비교군의 구간은 쓸 만하고 어느 것은 쓰면 안 되는지**를 판정해
출력에 붙입니다. 계획서 91~94행이 요구한 세 단계입니다.

```text
참고 가능                  구간폭 <= 30배    구간을 그대로 낸다
범위 넓음                  <= 100배           구간과 함께 '폭이 넓다'를 표기한다
참고 범위 제시 어려움           그 위             구간 대신 '편차가 커 제시하기 어렵다'
```

> 368배 구간을 "P10~P90 참고 범위"라고 내보내면, 담당자가 그 숫자를 근거로
> 쓸 수 없을 뿐 아니라 **근거가 있다고 오해합니다.** 안 내보내는 것이
> 정직합니다.

경계값은 M22 의 실측 분포에서 잡았습니다 — 연구개발/grant 18.8배,
판로/grant 24.5배, 사업화/grant 36.0배, 융자/loan 42.0배, 설비/grant 368.2배.

## 2. 전체 지표 (계획서 76~82행)

| 지표 | 값 |
|---|---:|
| Coverage (명목 80%) | 80.3% |
| Median Interval Width | 1.6139 log10 (**41.1배**) |
| Mean Interval Width | 1.6697 log10 |
| **Interval Score** (중앙) | **1.7740** |
| Interval Score (평균) | 2.4570 |
| MAE(log10) | 0.5164 |
| Median Absolute Error | 0.3897 |
| Pinball (P10 / P50 / P90) | 0.12507 / 0.25820 / 0.12063 |

> **Interval Score(Winkler)** 는 커버리지와 폭을 한 값으로 묶습니다 —
> `폭 + (2/α)·(하한 미달분 + 상한 초과분)`. 구간을 넓히면 첫 항이, 벗어나면
> 둘째 항이 벌점을 줍니다. 폭만 보거나 커버리지만 보면 한쪽으로 도망칠 수
> 있는데 이 지표는 둘을 같이 묶습니다.

## 5. 판정

**조건부 채택 — 구간을 기본 출력으로 두면 안 된다**

- 전체 커버리지 80.3% / 구간폭 중앙값 41.1배 — M22 에서 확인한 대로 더 좁힐 여지는 없다
- Interval Score 중앙값 1.7740 — 커버리지와 폭을 한 값으로 묶은 지표다. 폭만 보거나 커버리지만 보면 한쪽으로 도망칠 수 있다
- 판정 대상 1918행 중 '참고 가능' 22.1%, '범위 넓음' 포함 93.9%, '참고 범위 제시 어려움' 6.1%
- 가장 좁은 칸 연구개발 / grant 18.8배 / 가장 넓은 칸 설비 / grant 368.2배 — 하나의 폭으로 뭉뚱그려 낼 수 없는 이유다
- '참고 범위 제시 어려움' 로 판정된 칸은 구간을 내보내지 않고 그 사실을 표기한다. 폭이 100배를 넘으면 담당자가 근거로 쓸 수 없을 뿐 아니라 근거가 있다고 오해한다
- 비교군 30건 미만인 287행은 애초에 판정하지 않는다(비교군 부족)
- '참고 가능' 비중이 22.1% 로 낮다. 구간은 요청 시 보조 정보로 내고, 기본 출력은 percentile 위치로 두는 편이 안전하다
