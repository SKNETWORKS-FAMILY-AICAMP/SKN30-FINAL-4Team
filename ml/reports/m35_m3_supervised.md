# M35 — 모델 3 지도학습 기준선

> 계획서 §10 이 묻는 것은 "분류로 갈아타자"가 아닙니다.
> **사람이 정의한 label 과 현재 feature 사이에 학습 가능한 signal 이**
> **존재하는가** 를 가르는 실험입니다.

```text
35건 x 12축 / 양성 10
LeaveOneOut CV out-of-fold ROC-AUC + 라벨 순열검정 100회
```

## 1. 결과

| 모델 | LOO ROC-AUC | 라벨 섞음 평균 | 섞음 P95 | 순열 p |
|---|---:|---:|---:|---:|
| LinearSVM | **0.8760** | 0.3347 | 0.7092 | 0.010 |
| LogisticRegression | **0.8480** | 0.4742 | 0.6922 | 0.000 |
| MLP(16) | **0.8360** | 0.4725 | 0.6802 | 0.000 |
| LightGBM | **0.7840** | 0.4462 | 0.6402 | 0.000 |
| RandomForest | **0.7680** | 0.4482 | 0.6600 | 0.000 |

같은 35건에서의 비지도 기준선 (M34):

```text
distance only
ROC-AUC 0.9040
```

## 2. 라벨 순열검정을 같이 봐야 하는 이유

계획서 §9.4 그대로입니다. 라벨을 무작위로 섞고 **같은 절차**를 돌립니다.
정상적인 모델이라면 섞은 라벨에서는 AUC 가 0.5 근처로 떨어져야 합니다.
떨어지지 않으면 평가 절차나 데이터에 누수가 있다는 뜻입니다.

여기서는 반대 방향으로도 씁니다 — 실제 AUC 가 섞은 것들의 분포 안에
들어가면, 수치가 0.7 이든 0.8 이든 **35건에서는 우연과 구분되지 않습니다.**

## 3. 판정

**signal 있음 · 문제정의 유지**

- 지도학습 0.876, 비지도 최고 0.904(distance only) — 지도학습이 앞서지 않는다. 이상탐지라는 문제정의를 바꿀 근거가 없다.
- 라벨을 섞으면 AUC 가 0.335 로 떨어진다(순열 p=0.010). 평가 절차에 누수는 없다 — 계획서 §9.4 Random Label Test 통과.
- 양성 10건짜리 표본이다. 모델 간 AUC 차이는 읽지 않는다 — 읽을 수 있는 것은 '섞은 라벨과 구분되는가' 하나뿐이다.

## 4. 이 표로 하지 않는 것

- 모델 선택. 35건은 진단용이지 학습셋이 아닙니다.
- 모델 간 우열. AUC 차이 0.05 는 이 표본에서 의미가 없습니다.
- threshold 결정. 이 세트는 튜닝에 쓰지 않습니다.
